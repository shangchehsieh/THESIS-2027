Framework for Robust Brain Tumor Segmentation with Incomplete MRI Modalities Using Hölder Divergence and Mutual Information-Enhanced Knowledge Transfer — 依論文 Fig. 1 重繪，並改成這份 repo 目前的架構：DC 之前多了一層跨模態 self-attention（借 mmFormer 的 inter-modal transformer 構想）——每個模態在 decoder 最後一層的特徵 fi 上，逐 voxel 對其他存活模態做 attention 並以殘差加回（輸出投影 zero-init，所以起點就是 baseline），再各自過共用的 OutConv 得到 hi′，最後仍取均勻平均。左上的 U-Net inset 為程式碼實際使用的 3D U-Net（通道 16 → 128、GroupNorm、trilinear 上採樣）。

論文圖 vs. 實際程式碼的差異（讀 code 時要換算）
  • DC 前的 attention 是這份 repo 對論文唯一的架構改動。動機來自 RFNet 的模態–區域對應（FLAIR → 背景/水腫，T1c → NCR/ET，FLAIR+T2 → 水腫）以及我們自己 baseline 的 15-combo 明細：含 T1c 的組合 TC ≈ 0.88 / ET ≈ 0.84，不含 T1c 則 TC 掉到 0.75–0.80、ET 崩到 0.46–0.56。
  • 為什麼不是在 logit 上加權（上一版 Option A，已否決）：我們先試過「共用 conv gate 讀 hi → softmax 權重 → 加權和」，跑到 epoch 180 時每次 eval 都比 baseline 低 0.02–0.04、TC 最慘且差距不收斂。逐組合拆開看：TC 在有 T1c 的組合崩最兇（全 4 模態的 TC 甚至比 T1c 單獨還低——凸組合輸給最佳成員，代表權重系統性選錯），ET 只在沒有 T1c 的組合掉。診斷出四個結構性原因：gate 共用且只看 hi，不知道自己是哪個模態，只能學「誰的 logit 極端誰贏」；梯度穿過 gate 回到 hi，stream 被訓練去操縱自己的權重；富者越富的梯度飢餓；隨機初始化 + softmax 飽和。更根本的是「有 T1c 時 ET 一分不差」說明 logit 層重新加權沒有 headroom——它只能改票的權重，不能讓模態之間交換資訊。這一版把改動搬到特徵層、有 V（真的交換資訊）、有模態身份（ei）、zero-init，就是逐條回應這四點。
  • 快速路徑（數學上完全等價）：attention 之後的 O、OutConv、平均全是線性，所以 ŶS = meani∈S hi + meani∈S Σj∈S αij uj + c，其中 uj = WoutcWOWV(fj+ej) 只有 3 個通道、四個模態算一次共用；每個子集只剩「在存活模態間對預先算好的 4×4 分數做 softmax」和一個 3 通道的收縮。跟逐字實作的 attention 在 float64 下相差 2.7e-15。代價是 batch 8、128³ 時每 iter 14.1 s（baseline 6.5 s）、記憶體 68.5 GB（baseline 66 GB）。如果之後在 attention 和 OutConv 之間加任何非線性（FFN、norm），這個捷徑就不成立，要改回 ModalityAttnFusion.forward 的參考路徑。
  • softmax 只在「存活模態」之間做：推論時 preserved、訓練時每個 itertools.combinations 子集各遮一次，所以缺模態的資訊不會經由 attention 漏進子集的 loss。訓練階段一次前向就把全部 15 個子集的 loss 加總，並非隨機丟模態。
  • 沒動的部分：df = mean(di) 與 ℒMI 那一支完全保留（trainer.py:339、loss.py）；Encoder / Decoder、ℒdice、ℒHD、λ1 = λ2 = 1、15 子集枚舉、最終均勻平均都跟 baseline 相同，所以之後跟 gmd-enum-2-adam-acn-split2-lrfix 比就是純粹在比「特徵層有沒有跨模態交換」。
  • 論文原圖的 U-Net inset 是經典 2D U-Net（3→64→…→1024、輸出 2 類、up-conv、copy-and-crop）；這裡已改畫成實作版：3D、width_ratio=0.5 → 16 / 32 / 64 / 128 / 128、輸出 3 個 sigmoid 通道、padding=1 所以 skip 直接 concat、trilinear 上採樣後接兩個 Conv3d（Up.conv 的 DoubleConv）。
  • ℒMI inset 畫成每個 di 對 df；程式裡實際是每個子集的 mean(dsubset) 對 df，單模態只是 15 個子集中的 4 個。

元件來源我們怎麼用
跨模態 self-attention、缺模態從 token 集合遮掉mmFormer（Zhang et al., MICCAI 2022）的 inter-modal transformer 構想用在 decoder 最後一層特徵 fi（128³、16 ch），同一 voxel 的存活模態互為 token，token = fi + 可學的 modality embedding ei（這部分也是照 mmFormer，請翻論文確認）；輕量版：1×1 的 Q/K/V/O、單層、無 FFN。mmFormer 本身放在 bottleneck 且有完整 transformer block，這些差異之後可逐項補回來看有沒有幫助
MRT（Modality-Relation Transformer）PAMSRecon（劉恆，NTHU 論文）尚未實作，預計下一步放在 bottleneck 特徵 di（8³、128 ch），跟這一版是兩個不同插入點，可疊加；ℒMI 維持讀 attention 前的 di
輸出投影 O zero-init + 殘差做法等同 ControlNet（Zhang et al., 2023）的 zero convolution；ReZero（Bachlechner et al., 2020）是同精神但用可學純量 α = 0 的變體讓 attention 分支初始為恆等，epoch 0 與 baseline bit-identical；是初始化方式，不是新模組。（引用前請自行確認原文）
「各模態在特定腫瘤區域較可靠」的動機RFNet（Ding et al., ICCV 2021）只借動機；RFNet 的 conv 權重產生器與每模態輔助 loss 都沒有用
15 子集枚舉、最終均勻平均、ℒMI、ℒHDHD 論文本身（Cheng et al.）不動；attention 在每個子集內各做一次以維持訓練／測試一致
