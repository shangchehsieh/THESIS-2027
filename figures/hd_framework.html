1. self-bias 的最佳設定

做法內容目前證據成本
固定值掃描b = 0 / 1 / 2 / 3 / 4（b = 0 就是 v1）。b 越大，預設越相信自己（b = 2 約 71%，b = 4 約 95%）b = 0：80.07；b = 2：80.57（+0.50，仍在 ±1 噪音內）。b = 2 是依 v1 的分數差 1.84 選的，沒有比過其他值新增 b = 1、3、4 共 3 次訓練
可學習（有下限）每個模態一個可學習的 b，用 softplus 保證 ≥ 0P1 的可學習版本沒有下限，被訓練成 −0.42（反而不看自己），所以才改成固定值1 次訓練
自適應 self-biasb 依每個體素上「存在的模態彼此預測有多不一致」自動調整。各模態的預測本來就算好了，幾乎不增加成本，也不破壞 15 組加速計算尚未實作；方向（不一致時要提高還是降低 b）需要先定假設實作 + 1 次訓練

建議順序：先做固定值掃描。消融實驗是審查者最可能要求的，也能決定自適應版本的起點。

2. 架構是否太多：逐一拿掉（leave-one-out）

拿掉怎麼拿掉目前證據
ℒHD（Hölder divergence）只保留 Dice loss（需要新增開關）沒有資料。它是 HD 的核心，拿掉前要先和老師確認，否則論文的基礎就變了
ℒMIMI 權重設為 0（需要新增開關）沒有資料。它是目前唯一處理「缺失資訊」的機制（只在 latent）
self-biasmodel.self_bias=0疊加方向有：+0.50（v1 → sb2）
DWmodel.qk_dw_kernel=0疊加方向有：+0.20（sb2 → dwqk3）
GSSloss.gss.beta=0就是 dwqk3（80.77）；完整版的 test 結果待出

判斷規則：以完整版為基準，拿掉某個部分後分數變化小於 ±1 分（而且成對檢定不顯著），就考慮刪掉，讓論文更精簡。目前 self-bias 和 DW 的貢獻都在噪音內，這兩個最需要驗證。完整的 leave-one-out 需要 5 次訓練（約 15 天），可以先做 self-bias、DW、GSS 三個不用改程式的。

3. 其他建議

優先項目為什麼成本
高用逐例 binary Dice（PAMSRecon / RFNet 的算法）重算所有模型我們的 soft、每 8 例合併的算法和其他論文不同；同一組預測換算法，ET 可以差 6 分以上。要和別的論文比較就一定要做不用訓練
高逐例成對檢定（Wilcoxon）＋ 多跑 seed目前每一步的差距都在 ±1 分內，要證明不是噪音檢定不用訓練；seed 每次 3 天
中重新檢討「選最佳 epoch」的方式val 只有 50 例、波動大，而且 val 和 test 多次不一致。可以比較最後一個 epoch、最後幾個 checkpoint 平均的 test 結果不用訓練
中缺 FLAIR 和 T2 時的組合（只有 T1、只有 T1c、T1c+T1）這幾組一直是最弱的；GSS 就是針對它，test 結果出來先看這幾組不用訓練
低注意力分支過大（gain 11 到 13，修正量是直接路徑的 8 到 27 倍）之前限制它的大小沒有幫助；目前不影響結果，論文中可以當分析或限制來討論不用訓練
低整理參數量與訓練時間表論文通常要列；加速計算是我們的賣點，要有數字支持不用訓練
